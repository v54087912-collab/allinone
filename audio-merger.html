    Frequently Asked Questions

    Is there a file size limit for audio and video files?

    Because processing runs locally inside your browser, file size limits depend only on your device memory. Large media files can be processed without waiting for slow server uploads.

    Do my audio/video recordings get stored anywhere?

    No. All audio rendering and media extraction happen directly on your device. Zero bytes are uploaded to external servers.

    Can I export audio to MP3 or WAV?

    Yes, multiple standard formats including MP3, WAV, AAC, and OGG are supported.

    Does it require installing plugins?

    No plugins or software installs needed. Everything runs natively via Web Audio and HTML5 standards.
